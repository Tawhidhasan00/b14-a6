# FitLog

FitLog is a simple workout library and daily exercise planner. Users can browse workouts, view exercise details, add up to five workouts to today's plan, and save workouts for later. Plan and saved data are stored in the browser so they remain available after a page reload.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- DaisyUI
- React Icons
- React Toastify
- Browser Local Storage

## Features

- Browse workouts loaded from an API
- View workout details, equipment, statistics, and instructions
- Save exercises for later
- Keep plan and saved workouts after refreshing the page
- Search workouts in the Plan and Saved tabs
- Sort workouts by duration, calories, or rating
- Mark planned workouts as completed
- Remove workouts from the Plan or Saved list
- View live Plan and Saved counters in the navbar
- Receive toast notifications after important actions
- Use the application on mobile, tablet, and desktop screens
